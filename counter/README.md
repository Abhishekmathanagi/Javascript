# 🔢 JS Counter App

A simple, interactive counter application built with vanilla JavaScript, HTML, and CSS. This project demonstrates core JavaScript concepts, including DOM manipulation, event handling, type conversion, and conditional logic.

---

## 🚀 Features

* **Increment & Decrement:** Increase or decrease the counter value using dedicated buttons.
* **Reset Functionality:** Instantly reset the count back to zero.
* **Value Safeguards:** Uses conditional statements to set min/max boundaries (e.g., prevents negative numbers or limits max count).
* **DOM Synchronization:** Dynamically updates the displayed value in real-time.

---

## 🛠️ Concepts Applied

* **Event Listeners (`addEventListener`):** Captures user click events on buttons.
* **Type Conversion (`parseInt`):** Parses string content from HTML elements into numbers for mathematical operations.
* **Control Flow (`if / else`):** Applies logic to enforce upper/lower bounds on the counter.
* **DOM Manipulation:** Reads from and updates the DOM using `textContent`.
